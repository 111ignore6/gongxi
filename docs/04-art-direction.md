# 纸间 · 温暖克制的研究工作室

用户已选择主方向：纸白、墨色、陶土色，像舒适的研究工作室。产品暂名共席，视觉方案名纸间；名称未做商标检索。原型A为主案，B夜航和C庭院只保留为比较稿，真实实现聚焦A。

## 视觉语法

| 用途 | 色值 | 用法 |
|---|---|---|
| 空间背景 | #f3f1eb | 暖纸灰，拉开内容纸面的层次 |
| 内容表面 | #fbfaf7 / #fdfcf9 | 讨论与卡片，减少大块纯白刺激 |
| 主文字 | #282e28 | 墨色，长段文字的基准 |
| 次文字 | #62695e | 时间、说明，仍须可读 |

| 分隔 | #dfdfd3 | 细线和轻边框，不承担唯一状态表达 |

标题采用系统宋体/衬线回退，正文采用Microsoft YaHei UI/Segoe UI等系统字体，避免下载外部字体和许可不清资产。正文目标15–16px，中文行高1.7–1.85；按钮/次信息不为塞内容压成极小字。每段宽度适合阅读，长英文/URL必须换行。

桌面左侧项目导航，中部讨论与输入，右侧放共同方向和摘要。决定、任务各有独立页面，避免把“完成”藏在聊天滚动中。窄屏收起辅助面板，保持主要操作可达；表单标签必须可见，不能只靠placeholder。

## 状态与交互

人类/AI用身份文字+头像形状辅助区分。最后请求时间不写成“正在思考”；方向发布不自动填满确认进度。主按钮陶土，危险操作需说明对象；加载与失败不清空编辑内容。键盘焦点有明显轮廓，弹窗可Esc关闭，异步通知可被辅助技术读取。动画克制，并响应prefers-reduced-motion。

最低文字对比目标普通文字4.5:1，大号文字3:1；这是[WCAG 2.2 SC1.4.3官方说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)的要求。色值表不是自动合规证明，需要对真实前景/背景组合逐项验证，禁用态和装饰线不能充当正文。
